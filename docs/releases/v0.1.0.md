# mojo-systemd v0.1.0

**Released:** 2026-10-21 · **Commit:** the one tagged v0.1.0 · **Previous:** first release

## What it does

sd_notify for Mojo: a service tells systemd it is ready, what it is doing, and that it is alive.

## Highlights

- 60 lines, libc only; no libsystemd to link.
- A real `Type=notify` unit with `WatchdogSec=1` is part of the gate: pinging survives, silence is killed.
- Path and abstract sockets; `WATCHDOG_PID` respected.

## Changes

First public release, no earlier version.

## Known limits

- Linux only. No `FDSTORE`/fd passing (needs `SCM_RIGHTS`), no `sd_listen_fds`.
- On a runner without a user service manager the unit test is skipped and says so.
